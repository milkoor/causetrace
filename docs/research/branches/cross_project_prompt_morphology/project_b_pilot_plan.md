# Project B Pilot Plan

This is the second pilot application repo for the cross-project prompt morphology study.

The concrete 5-task pilot is defined in:

- [Project B 5-task pilot](project_b_5task_pilot_v0.1.md)

## Why This Repo

`Project B` is useful for testing whether prompt morphology effects carry over from calibration-heavy tasks into business workflow and application development tasks.

## Suggested Task Types

- feature addition
- business logic fix
- workflow adjustment
- refactor
- review
- API or form behavior correction

## Suggested Pilot Scope

- 3 to 5 real tasks
- 2 to 3 prompt variants per task
- 1 fixed runtime where possible
- same commit baseline across variants

## What to Measure

- whether expanded prompts improve task closure
- whether expanded prompts reduce unnecessary back-and-forth
- whether expanded prompts increase or decrease correction triggers
- whether prompt structure changes trace morphology in business logic work

## Project Output

Produce a project-level decision page answering:

- should automatic prompt expansion be recommended here
- which task types benefit
- which task types are over-constrained
- which prompt templates are reusable
- what task description rules should be adopted
- how the result should be reflected in `Project B` execution practice
