# Cross-project Summary Template

Use this template only after each project has been analyzed independently.

## Scope

- projects included
- task families included
- runtimes included
- prompt variants included

## Shared Trends

- trend observed in both projects
- trend observed in only one project
- magnitude of difference

## Divergences

- where the projects differ
- whether the divergence is task-driven, runtime-driven, or project-driven

## Decision Output

- automatic prompt expansion recommended globally or not
- automatic prompt expansion recommended only per project
- task classes that benefit
- task classes that should stay short

## Caveats

- sampling limits
- runtime imbalance
- task imbalance
- possible contamination from prior runs
