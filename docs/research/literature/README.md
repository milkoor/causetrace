# Literature Review Matrix

This index tracks external research that can inform causetrace hypotheses, terminology, and future phase planning. It does not promote external concepts into core facts by itself.

## How to use this index

- Treat all entries as literature signals, not corpus evidence.
- Use them to seed hypotheses and route corrections.
- Do not import their terminology into the core taxonomy without causetrace corpus validation.
- Keep them separate from native / controlled benchmark / external trajectory lane accounting.

## Literature-Driven Guardrails

- External research can suggest hypotheses.
- External research cannot alter readiness gates, taxonomy labels, or corpus conclusions without causetrace evidence.
- External research should be recorded in the literature index before it affects analysis language.
- Controlled benchmark candidates remain candidates until manually reviewed and lane-assigned.

## Suggested next steps

- Keep literature notes small and explicit.
- Attach each new paper to a hypothesis or phase planning note.
- Revisit this matrix only when a paper changes a concrete question in the corpus plan.
